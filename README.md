# Simple Reservation System

A console-based reservation manager built in Java. It allows creating, viewing, rescheduling, and cancelling a reservation in memory during execution.

## Features

- Create reservations
- Check details of the active reservation
- Reschedule dates and times
- Cancel existing reservations with security confirmation

## Technologies used

- Java — core logic and object-oriented structure
- Scanner (java.util.Scanner) — console input handling

## How to run the project

### Requirements

- Java JDK 11 or higher installed

### Steps

1. Clone this repository:
```Bash
git clone <repository-url>
```

2. Compile the Java files:
```Bash
javac Main.java GerenciadorReservas.java
```

3. Run the program:
```Bash
java Main
```
